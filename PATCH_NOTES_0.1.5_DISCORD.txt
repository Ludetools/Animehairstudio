# Anime Hair Studio Version 0.1.5 Patch Notes
**August 12, 2026**

## New Features

**Autosave and Crash Recovery**
Anime Hair Studio can now keep a local recovery copy of your project while you work. Autosave runs after committed changes without interrupting active edits, and Preferences includes controls for enabling it and choosing how frequently it saves.

**Material Presets**
You can now save a material as a reusable preset and apply it in other projects. Material presets retain the reusable appearance settings without carrying over project-specific material assignments.

**Base Color Gradients**
Hair materials can now use an editable color gradient instead of a single base color. Gradient stops control how the color changes along the strand and are evaluated directly by the hair material for a responsive preview.

## New Features - Continued

**Expanded Selection Sets**
Selected strands can be added to or removed from an existing set, and sets can hide, show, lock, unlock, or select all of their members from the outliner. The eye button beside a set controls every member's visibility and shows a partial state when only some members are visible.

**Camera View Cube**
Click Front, Back, Left, Right, Top, or Bottom on the view cube to snap directly to that view. Top and Bottom use a stable camera orientation so normal orbiting still behaves correctly afterward.

**Multi-Cam View**
The experimental Multi-Cam option divides the viewport into four equal views. Each view has its own camera and can be activated by clicking inside it. Perspective remains freely orbitable, while cardinal views use orthographic projection with independent pan and zoom controls.

## New Features - Continued

**Numeric Object Transforms**
Object Edit Mode now includes a compact floating Transform panel. Translation, Rotation, and Scale can be entered directly, and each individual axis has its own reset button. Values update alongside viewport gizmo edits.

**Viewport Curve Controls for Move**
Move tool settings can expose Width, Depth, and Twist Curve controls directly on the strand. Width and Depth can switch between symmetrical and asymmetrical editing, and optional Width, Depth, or Uniform grab handles provide faster profile scaling.

**Relax Position and Rotation Separately**
The Relax tool has independent Position and Rotation controls. Position follows the surrounding curve, while Rotation smooths the authored orientation and displays the normal direction in the viewport.

**Split Panel Tip Curvature**
Split Panel strands have a signed tip-curvature control for shaping curved fringes in either direction. Additional tip density can be added where the split needs more detail, and open split boundaries can be displayed as hard edges.

**Branch Surface Imprints**
Attached branch strands can project their profile intersection onto the parent as additional topology. The imprint remains part of the parent geometry when the branch is hidden.

## UI Changes

**Customizable Panel Styles**
Preferences offers Default Panels, No Panels, and Glass Panels. No Panels extends the viewport behind the interface, while Glass Panels retains the panel structure with a translucent glass treatment.

**Custom Glass Color**
The Glass Panels color can be changed or reset from Preferences. The color is shared by side panels, workspace controls, top viewport controls, dropdowns, tabs, and other glass-styled elements while preserving their value differences.

**Responsive Viewport Header**
Compact square buttons are aligned around the Workspace, Live Surface, and Layer controls. When horizontal space is limited, the buttons move to a second row while the dropdown groups avoid overlapping.

**Pie-Style Radial Menus**
Radial actions use pie-menu sectors with subtle dividers and a cyan hover gradient. Hovering over a submenu reveals smaller actions in a nearby outer ring, while lower-priority commands remain in the list beneath the menu.

**Cleaner Interface Interaction**
Interface labels are no longer accidentally selectable, while text fields and Patch Notes remain selectable. No Panels mode also uses simplified scrollbars and transparent outliner region rows.

## Tweaks and Quality of Life

- Press **Ctrl+H** with strands selected to hide them. Press it with nothing selected to unhide all hidden strands.
- Rebuild Curve appears in the strand radial ring when space is available and in the action list when the ring is full.
- **Ctrl+D** and the other duplicate commands work with selected Guides and References in their respective workspaces.
- Strands can be dragged into another outliner region and receive an appropriate unique name.
- Isolated View and Live Surface changes are excluded from Undo history.
- Recognized viewport shortcuts work after using checkboxes, toggles, dropdowns, and sliders.
- Hold **S** and drag to resize the Move or Smooth brush while keeping the cursor anchored.
- Preserve Tips has an independent state for each applicable brush.

--- COPY MESSAGE 6/7 ---

## Tweaks and Quality of Life - Continued

- Zipper controls share the curve control-point display size and its preference.
- The UV checker remains responsive on larger hairstyles, and exported UVs use the expected orientation in applications such as Maya.
- Split Panel topology uses quads wherever the profile retains distinct corners, with triangles limited to collapsed taper regions.
- Proportional Editing uses a lighter influence display that disappears when the selection is cleared.
- Undo and Redo remain responsive with many visible strands.
- Locked strands use a restrained grey treatment with a subtle translucent magenta wireframe.
- Viewport shadows update live as strands, guides, lighting, and the camera change.

## Bug Fixes

- Linked mirrored strands correctly reverse asymmetric Width Curve profiles.
- Branch roots remain attached to their parent control points during object and hierarchical transforms.
- Attached branches retain their authored orientation through large parent rotations.
- Open curve editor windows follow the active strand when the selection changes.
- Viewport Width, Depth, and Twist Curve controls stay attached to rebuilt strand geometry.
