# Anime Hair Studio 1.0.0

A browser-based 3D tool for creating stylized and anime-inspired hairstyles.

## Run

1. Install [Node.js](https://nodejs.org/) on Windows 10 or 11.
2. Download this repository and extract it.
3. Double-click **Start Anime Hair Studio.cmd**.

The launcher opens the app in your browser and starts the local save/export service. No npm package installation is needed. An internet connection is required to load Three.js from unpkg.

Alternatively, run `node server.js` and open http://127.0.0.1:5173/.
Use the launcher rather than opening index.html directly for native save and export support.

Patch notes and keyboard shortcuts are available in the app's Help menu. Back up your projects regularly.
