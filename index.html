Anime Hair Studio Version 0.1.3 Patch Notes

New modeling workflows, project tools, viewport controls, and quality-of-life improvements.

Curve editing and selection

  • Alt-click a selected control point to remove it from the active selection.
  • Alt-click a selected strand to remove it from the active selection.
  • Shift+Ctrl-click a curve to insert a control point. Nearby points redistribute themselves to accommodate it while maintaining the previous curve shape.
  • Shift+Alt-click a control point to remove it while preserving the surrounding curve shape. Removing the tip shortens the curve, while attempting to remove the root has no effect.
  • Added Curves → Rebuild Curve to the title bar. This lets you change the number of control points on one or multiple selected curves while retaining their shape. Control points can also be evenly distributed along the curve.
  • Delete now removes selected strands, removable guides, or references. Scene-critical elements such as the scalp guide remain protected.
  • Ctrl+D duplicates the selected strand or strands and lets you position the duplicates with the mouse.
  • Alt+D with two strands selected enters Procedural Duplicate mode. Newly placed strands blend between the shapes of the two source strands according to their proximity. Click repeatedly to place strands, then press Enter or Alt+D to exit. This is an early implementation and may still be buggy.
  • Holding Shift before or during a Draw Strand, Braid, or Split Panel stroke constrains the stroke to eight directions in 45-degree increments while keeping it conformed to the active surface.
  • The F shortcut now cycles between framing the current selection and framing the complete scene.

New modeling tools

  • Added Move and Smooth sculpt brushes to the bottom of the viewport, with adjustable radius, strength, and falloff.
  • Added Curve Lattice as a new guide type.
  • Added asymmetric width and depth curves.
  • Width and depth curve points can optionally be displayed and edited directly on the strand mesh.

References

  • Added the ability to crop 2D overlay reference images directly in the viewport.
  • Fixed the Left and Right 3D reference-plane assignments being reversed.
  • Added a preference for switching Left/Right naming between Viewport Perspective and Character Perspective.

Materials and viewport inspection

  • Added a toon-style Anime Anisotropic hair shader with configurable shadow bands, soft shadows, highlights, rim lighting, anisotropy, and highlight noise.
  • Restored the Lambert shader.
  • Added a preference for choosing the default shader used by new projects.
  • Added a UV Checker debug view.
  • Added a movable UV Inspector window for examining selected mesh topology in UV space.

Files and export

  • Added USDA export with support for mesh geometry, UVs, and editable strand center curves.
  • Added save and export dialog windows where you can name the file and choose which supported scene elements to include.
  • Project files now use the .ahs extension. Existing .animehair.json project files can still be opened.
  • Removed the old Maya Python export path. USDA is now the primary format for exporting editable curves.
  • Bones and weights are shown in the export dialog as planned export categories, but remain unavailable until skeleton and skin-weight authoring are implemented.

Presets and preferences

  • Added a preference for increasing or decreasing the display size of strand control points.
  • Added Compact Tool Buttons mode, which reduces viewport tools to smaller icon-only buttons.
  • Added an option to enable or disable region colors on outliner folders.
  • Preferences and custom presets can now be downloaded to a backup file and restored later. Browser storage still saves them automatically, but keeping an external backup is recommended.
  • Added custom presets for strand profiles and width/depth curves.
  • Clumps can now be saved as reusable Draw Strand brush presets.

Outliner and UI

  • Made the outliner more compact.
  • Added inline renaming for strands, clumps, guides, and references.
  • Added more contextual outliner actions for selections, clumps, guides, references, and mirror instances.

Bug fixes and improvements

  • Fixed Undo and Redo changing the current X-mirror editing setting.
  • Fixed recognized viewport shortcuts sometimes failing when a dropdown or range slider had focus. Text and number fields retain normal editing behavior.
