Anime Hair Studio Version 0.1.5 Patch Notes

Autosave recovery, material gradients, customizable panels, camera tools, and expanded editing workflows.

New features

  • Autosave and Crash Recovery
    Anime Hair Studio can now keep a local recovery copy of your project while you work. Autosave runs after committed changes without interrupting active edits, and Preferences includes controls for enabling it and choosing how frequently it saves.
  • Material Presets
    You can now save a material as a reusable preset and apply it in other projects. Material presets retain the reusable appearance settings without carrying over project-specific material assignments.
  • Base Color Gradients
    Hair materials can now use an editable color gradient instead of a single base color. Gradient stops control how the color changes along the strand and are evaluated directly by the hair material for a responsive preview.
  • Expanded Selection Sets
    Selected strands can be added to or removed from an existing set, and sets can hide, show, lock, unlock, or select all of their members from the outliner. The eye button beside a set controls every member's visibility and shows a partial state when only some members are visible.
  • Camera View Cube
    Click Front, Back, Left, Right, Top, or Bottom on the view cube to snap directly to that view. Top and Bottom use a stable camera orientation so normal orbiting still behaves correctly afterward.
  • Multi-Cam View
    The experimental Multi-Cam option divides the viewport into four equal views. Each view has its own camera and can be activated by clicking inside it. Perspective remains freely orbitable, while cardinal views use orthographic projection with independent pan and zoom controls.
  • Numeric Object Transforms
    Object Edit Mode now includes a compact floating Transform panel. Translation, Rotation, and Scale can be entered directly, and each individual axis has its own reset button. Values update alongside viewport gizmo edits.
  • Viewport Curve Controls for Move
    Move tool settings can expose Width, Depth, and Twist Curve controls directly on the strand. Width and Depth can switch between symmetrical and asymmetrical editing, and optional Width, Depth, or Uniform grab handles provide faster profile scaling.
  • Relax Position and Rotation Separately
    The Relax tool has independent Position and Rotation controls. Position follows the surrounding curve, while Rotation smooths the authored orientation and displays the normal direction in the viewport.
  • Split Panel Tip Curvature
    Split Panel strands have a signed tip-curvature control for shaping curved fringes in either direction. Additional tip density can be added where the split needs more detail, and open split boundaries can be displayed as hard edges.
  • Branch Surface Imprints
    Attached branch strands can project their profile intersection onto the parent as additional topology. The imprint remains part of the parent geometry when the branch is hidden.

UI changes

  • Customizable Panel Styles
    Preferences offers Default Panels, No Panels, and Glass Panels. No Panels extends the viewport behind the interface, while Glass Panels retains the panel structure with a translucent glass treatment.
  • Custom Glass Color
    The Glass Panels color can be changed or reset from Preferences. The color is shared by side panels, workspace controls, top viewport controls, dropdowns, tabs, and other glass-styled elements while preserving their value differences.
  • Responsive Viewport Header
    Compact square buttons are aligned around the Workspace, Live Surface, and Layer controls. When horizontal space is limited, the buttons move to a second row while the dropdown groups avoid overlapping.
  • Pie-Style Radial Menus
    Radial actions use pie-menu sectors with subtle dividers and a cyan hover gradient. Hovering over a submenu reveals smaller actions in a nearby outer ring, while lower-priority commands remain in the list beneath the menu.
  • Cleaner Interface Interaction
    Interface labels are no longer accidentally selectable, while text fields and Patch Notes remain selectable. No Panels mode also uses simplified scrollbars and transparent outliner region rows.

Tweaks and quality of life

  • Press Ctrl+H with strands selected to hide them. Press it with nothing selected to unhide all hidden strands.
  • Rebuild Curve appears in the strand radial ring when space is available and in the action list when the ring is full.
  • Ctrl+D and the other duplicate commands work with selected Guides and References in their respective workspaces.
  • Strands can be dragged into another outliner region and receive an appropriate unique name.
  • Isolated View and Live Surface changes are excluded from Undo history.
  • Recognized viewport shortcuts work after using checkboxes, toggles, dropdowns, and sliders.
  • Hold S and drag to resize the Move or Smooth brush while keeping the cursor anchored.
  • Preserve Tips has an independent state for each applicable brush.
  • Zipper controls share the curve control-point display size and its preference.
  • The UV checker remains responsive on larger hairstyles, and exported UVs use the expected orientation in applications such as Maya.
  • Split Panel topology uses quads wherever the profile retains distinct corners, with triangles limited to collapsed taper regions.
  • Proportional Editing uses a lighter influence display that disappears when the selection is cleared.
  • Undo and Redo remain responsive with many visible strands.
  • Locked strands use a restrained grey treatment with a subtle translucent magenta wireframe.
  • Viewport shadows update live as strands, guides, lighting, and the camera change.

Bug fixes

  • Linked mirrored strands correctly reverse asymmetric Width Curve profiles.
  • Branch roots remain attached to their parent control points during object and hierarchical transforms.
  • Attached branches retain their authored orientation through large parent rotations.
  • Open curve editor windows follow the active strand when the selection changes.
  • Viewport Width, Depth, and Twist Curve controls stay attached to rebuilt strand geometry.
  • Tool shortcuts remain available while editing viewport curve points and after interacting with compatible panel controls.
  • Move Brush selection masking continues to update linked mirror instances.
  • Undo preserves Move Brush curve and control-point overlays without revealing unrelated controls.
  • Relax Rotation interpolates consistently across wrapped angles.
  • Guide Capsule radius changes preserve the capsule's position.
  • Standard object-mode marquee selection selects the strands inside the drag rectangle.
  • Top and Bottom camera snaps preserve stable orbit behaviour when returning to perspective.
  • Radial submenu labels, dividers, hover regions, bottom sectors, and action lists remain aligned and selectable.
  • Panel content and responsive layouts behave consistently across all three panel styles.
  • Texture updates wait for valid image data, preventing the associated Three.js warning.
  • Open zipper boundaries receive hard edges, while closed splits remain seamless.

New tools

  • Object Edit Mode
    Component and Object are now the two edit modes. Component edits curves and control points, while Object moves, rotates, or scales a complete strand or guide from its root.
  • Branch Strands
    Start a Draw Strand stroke from a control point on a selected strand to create a separate branch. Its root stays attached to the parent while the branch remains independently editable.
  • Twist Curve
    The Twist Curve controls clockwise or counterclockwise rotation along a strand. Its points support custom values, positions, and interpolation, and can be displayed directly beside the mesh for editing.
  • Draw Capsule Guide
    Sketch a curve to create a tapered capsule-shaped drawing surface. Step controls its loop spacing and one profile controls its width and depth taper.
  • Sculpt Proportional Editing
    Move and Smooth Brush can extend their influence beyond the main brush radius using an adjustable falloff.
  • Turntable Preview
    Turntable automatically orbits the camera around the hairstyle. Its speed can be adjusted from the Main tab while Turntable is active.

New features

  • Selection Sets
    You can now create Selection Sets by selecting multiple strands and choosing Create Selection Set from the Spacebar radial menu or outliner context menu. Sets can be recalled, renamed, or updated later.
  • Strand Locking
    You can now lock strands by selecting them and pressing L, using the radial menu, or using an outliner context menu. Locked strands cannot be selected or edited. Press L with nothing selected to unlock every strand.
  • Isolated View
    Select the strands you want to isolate and press Ctrl+1, or use Isolate in the radial menu, to toggle a view containing only those strands.
  • Relative Multi-Strand Editing
    Compatible settings can be changed across several selected strands without forcing them all to the same value. Their existing differences are preserved.
  • Mirror Strands and Clumps
    Strands and complete clumps can create linked mirrored instances. The linked partner updates automatically and can be decoupled later for independent editing.
  • Sculpt Selection Masks
    When strands are selected, Move and Smooth Brush affect only that selection. Every other strand is darkened and protected from the brush.
  • Twist Density
    Dynamic Density can add support loops where the Twist Curve needs them without increasing topology across the whole strand.
  • Recent Projects
    File → Recent Projects provides up to ten recently opened or saved projects.
  • Full Body Mesh Import
    Full-body OBJ meshes can be imported from the File menu or by drag and drop. They are scaled to roughly seven heads tall and aligned to the scalp guide.
  • Shareable Hair-Only Projects
    The Save window can exclude character meshes and references when you only want to share the hairstyle.

Editing improvements

  • Selection Modifiers
    Shift-click or Shift-drag adds to the selection. Ctrl-click or Ctrl-drag removes from it.
  • Selection While Transforming
    Move, Rotate, and Scale now use the same click and marquee selection controls as the Select tool.
  • Precision Transforms
    Hold Shift during Move, Rotate, or Scale for finer control. Scale Sensitivity can also be adjusted in the Scale tool settings.
  • Strand Rotation
    The complete strand profile can be rotated without changing its control-point normals.
  • Move Brush Influence
    Move Brush now captures its affected area on the initial click, so dragging does not pull new control points into the stroke.
  • Smooth Brush Preserve Tips
    Preserve Tips allows Smooth Brush to relax a curve without moving its endpoint.
  • Live Surface Controls
    Live Surface chooses which guide new strands conform to. Dynamic adds a contextual camera-facing drawing plane to that surface.
  • Guide Visibility
    Click the guide-visibility button to cycle through guide types, or right-click it to choose exactly which types are visible.

Files and projects

  • Project Drag and Drop
    Drop an .ahs file into the app to open it. A confirmation warns that unsaved work will be lost.
  • OBJ Drag and Drop
    Drop an OBJ file to import it as a Head Mesh or Full Body Mesh without opening the reference-image workflow.
  • Hair-Only Project Loading
    Projects saved without a character mesh reopen without inserting the default head.

UI/UX

  • Workspaces
    The former Strands, Guides, and References edit modes are now organized as workspaces. Use 1, 2, and 3 to switch workspaces; Tab switches between Component and Object edit modes.
  • Radial Menus
    Hold Spacebar to open context-sensitive actions and submenus without leaving the viewport. Holding a tool shortcut opens settings for that tool.
  • Blender Navigation
    Preferences now includes Blender-style Middle Mouse navigation. Navigation tips and the Shortcuts viewer update to match the selected style.
  • Viewport Preferences
    Camera smoothing, viewport background color, control-point size, Compact Tool Buttons, and outliner region colors can be adjusted in Preferences.
  • Character Mesh Visibility
    Head and body mesh visibility can be toggled from the Display tab.
  • Responsive Outliner
    On narrower windows, the outliner docks into the right panel and expands when the Attribute Editor is collapsed.
  • Layered Side Bun Preset
    A complete human-authored hairstyle is included as a starting point.
  • Patch Notes History
    The Patch Notes viewer now includes a dated sidebar for browsing previous updates.

Performance

  • Selecting, transforming, and sculpting large groups of strands should now remain more responsive.
  • Object-mode transforms use lighter live previews before rebuilding final strand geometry.
  • Sculpt brushes perform less work on strands that cannot be affected by the current brush stroke.

Bug fixes

  • Undo no longer reverts multiple actions after drawing a new strand following an undo.
  • Selection highlighting remains visible across the available shaders and on lighter hair colors.
  • Control points on newly drawn strands can now be selected reliably in a new scene.
  • Width, depth, and twist editors now refresh after Undo, Redo, and live geometry changes.
  • Large rotations no longer flip strand frames or unexpectedly change authored control-point normals.
  • OBJ files containing unsupported line or point primitives no longer cause valid face geometry to appear as wireframe-like lines.
  • Several guide visibility, scalp editing, raycasting, and narrow-window layout issues have also been fixed.

Misc

  • Patreon and Ko-fi support links have been added to the title bar.
  • Object Mesh remains a planned OBJ import type and is not implemented yet.
  • Recent Projects depends on locally stored browser data.

Curve editing and selection

  • Ctrl-click a selected control point to remove it from the active selection.
  • Ctrl-click a selected strand to remove it from the active selection.
  • Shift+Alt-click a curve to insert a control point. Nearby points redistribute themselves to accommodate it while maintaining the previous curve shape.
  • Shift+Ctrl-click a control point to remove it while preserving the surrounding curve shape. Removing the tip shortens the curve, while attempting to remove the root has no effect.
  • Added Curves → Rebuild Curve to the title bar. This lets you change the number of control points on one or multiple selected curves while retaining their shape. Control points can also be evenly distributed along the curve.
  • Delete now removes selected strands, removable guides, or references. Scene-critical elements such as the scalp guide remain protected.
  • Ctrl+D duplicates the current selection. Strand copies can be positioned with the mouse, while guide and reference copies are created in place and selected for editing.
  • With two strands selected, hold Spacebar and choose Duplicate Procedural to open a window that creates evenly spaced blended strands between them.
  • Holding Shift before or during a Draw Strand, Braid, or Split Panel stroke constrains the stroke to eight directions in 45-degree increments while keeping it conformed to the active surface.
  • The F shortcut now cycles between framing the current selection and framing the complete scene.

New modeling tools

  • Added Move and Smooth sculpt brushes to the bottom of the viewport, with adjustable radius, strength, and falloff.
  • Added Curve Lattice as a new guide type.
  • Added asymmetric width and depth curves.
  • Width and depth curve points can optionally be displayed and edited directly on the strand mesh.

References

  • Added the ability to crop 2D overlay reference images directly in the viewport.
  • Fixed the Left and Right 3D reference-plane assignments being reversed.
  • Added a preference for switching Left/Right naming between Viewport Perspective and Character Perspective.

Materials and viewport inspection

  • Added a toon-style Anime Anisotropic hair shader with configurable shadow bands, soft shadows, highlights, rim lighting, anisotropy, and highlight noise.
  • Restored the Lambert shader.
  • Added a preference for choosing the default shader used by new projects.
  • Added a UV Checker debug view.
  • Added a movable UV Inspector window for examining selected mesh topology in UV space.

Files and export

  • Added USDA export with support for mesh geometry, UVs, and editable strand center curves.
  • Added save and export dialog windows where you can name the file and choose which supported scene elements to include.
  • Project files now use the .ahs extension. Existing .animehair.json project files can still be opened.
  • Removed the old Maya Python export path. USDA is now the primary format for exporting editable curves.
  • Bones and weights are shown in the export dialog as planned export categories, but remain unavailable until skeleton and skin-weight authoring are implemented.

Presets and preferences

  • Added a preference for increasing or decreasing the display size of strand control points.
  • Added Compact Tool Buttons mode, which reduces viewport tools to smaller icon-only buttons.
  • Added an option to enable or disable region colors on outliner folders.
  • Preferences and custom presets can now be downloaded to a backup file and restored later. Browser storage still saves them automatically, but keeping an external backup is recommended.
  • Added custom presets for strand profiles and width/depth curves.
  • Clumps can now be saved as reusable Draw Strand brush presets.

Outliner and UI

  • Made the outliner more compact.
  • Added inline renaming for strands, clumps, guides, and references.
  • Added more contextual outliner actions for selections, clumps, guides, references, and mirror instances.

Bug fixes and improvements

  • Fixed Undo and Redo changing the current X-mirror editing setting.
  • Fixed recognized viewport shortcuts sometimes failing when a dropdown or range slider had focus. Text and number fields retain normal editing behavior.

Editing and navigation

  • Reworked the transform gizmo for a more predictable feel.
  • Clicking a control point through the gizmo now selects the point, while holding selects the gizmo instead.
  • Added an orthographic view toggle.
  • Added Strands, Guides, and References edit workspaces through a viewport dropdown. Objects outside the active workspace are not selectable.

References and outliner

  • Added 2D overlay references that can be positioned in the viewport background.
  • Added 3D reference planes that can be assigned to orthographic views and hidden outside their matching view.
  • Images can be dragged into the viewport or directly into the References tab.
  • Added Strands, Guides, and References tabs to the outliner, including visibility controls for each type.

Preferences and shortcuts

  • Added a Preferences window under Settings.
  • Preferences include navigation-tip, tooltip, viewport-statistics, and experimental-feature controls.
  • Added S + left-drag to resize the active brush.
  • Added the Keyboard Shortcuts viewer under Help.
  • Added quick Live Surface and Layer dropdowns to the viewport.

Experimental radial menus

  • Added tool radial menus that appear while holding a tool shortcut and expose contextual settings.
  • Added a Spacebar selection menu with contextual actions such as mirror, duplicate, and delete.
  • Radial menus were experimental in this release and could be enabled in Preferences.

Hair cards

  • Added an early Hair Card toggle that removes strand back planes while retaining the existing strand settings.

New tools

  • Added the experimental Panel Strand tool for flat hairstyles, with procedural splits controlled by zipper points.
  • Panel strands snap to loops by default so shared points can weld into watertight geometry.
  • Added Capsule Guides as editable live surfaces for drawing strands. In this release, capsules generated only for the scalp.

Strand editing

  • Added an experimental single split to Draw Strand. The early implementation produced two meshes rather than one airtight mesh.
  • Added strand-profile trimming and Linear interpolation alongside Smooth interpolation.
  • Added Redo.
  • Added mirrored strand instances through the outliner. Linked instances update together and can be decoupled.
  • Strands can be dragged onto one another to create a clump, and clumps can be dissolved from the outliner.
  • Added experimental region-wide editing from the attribute editor.

Visibility and interface

  • Added Display-tab visibility controls for guide types and strand regions and layers.
  • Introduced a desktop-style title bar with File and Edit menus.
  • Reorganized the right attribute editor into Main, Display, and Materials tabs.
  • Added a Discord link under Help.

Materials

  • Changed the default material from Lambertian diffuse to a standard PBR shader with anisotropic highlights.
  • Roughness was the only exposed shader parameter in this release.

Bug fixes

  • Restored online project downloads, using the browser's default download location.
  • Added a head-transparency toggle to expose hidden control points in the Scalp editor.
  • Removed unused controls.
