# Strand bundle brush — first version

## Experimental access

Enable **Accessory Brushes** under Preferences → Experimental with **Show Dev Test Features** enabled. This reuses the existing default-off procedural-draw preference, including preference save/restore; previous explicit opt-ins are preserved. Both the builder tab and drawing tool require the switch. Turning either switch off returns an active accessory builder to Pattern Brush and an active accessory drawing tool to Select. Saved recipes and completed objects remain intact and editable; Pattern Brush remains normally available. No geometry or project schema changes are involved in this gate.

## Individually authored chunky accents

The starter now includes a root flick and a shorter side lock, in addition to the main mass and four subdued medium locks. Flyaways remain off. Add/remove up to eight Chunky Accents in the recipe editor. Each owns attachment (root-to-tip fraction), angle around the strand, relative width, depth ratio, length fraction, signed flow direction, outward reach, and bend. A negative flow makes the root flick point back against the main flow. These are deliberate placements, unaffected by rerolling distributed layers.

Accents are normalized recipe data; old recipes default to an empty list. Save Recipe and pointer-down recipe snapshots include them. Preview and drawing share the existing template mapper, using a fixed local attachment frame for independently directed accents. Completed clumps use existing baked strand geometry, history, mirroring and project/export paths; recipe edits do not regenerate existing objects. No new project schema or interaction mode. Acceptance: add/edit/remove, load starter/reset, save/reload, deterministic independent accents, upward/downward finite geometry, and silhouette review. Head/scalp attachment is deferred until drawing, not assigned in the builder.

## Ponytail starter and curved preview

Brushes → Accessory → **Load Ponytail Recipe** loads an editable starter with one dominant main shape and four subordinate medium strands, seed 12. Flyaways are currently set to zero while the large/medium balance is tuned. The main width and depth curves retain volume farther down the strand. Medium locks use 20% relative width, full surface following and a late 72% release with restrained separation; they accent the surface without replacing the main silhouette. Loading replaces only the working builder recipe; **Save Recipe** explicitly stores it. Existing saved recipes and scene objects are not overwritten.

**Release point** (0–0.95 of each accessory's length) makes a lock start embedded, emerge along the main surface, then peel away smoothly. Tip separation controls the final offset. Accessory placement now uses the actual unit-radius sweep profile for this mode, rather than the old half-radius assumption that buried medium locks. Flyaways taper at both ends. Each layer owns its release value; normalization, recipe saving and stroke snapshots preserve it. An empty/missing value selects the unchanged legacy placement path, so existing saved recipes are not silently reinterpreted. Completed scene clumps remain baked and unchanged. This is a stylized starter, not a specific character recreation or collision-free hair solver.

**Preview** offers Straight, Curved, and Compare (straight left, curved right). Both use equal-length test strokes and the exact `drawClumpStrandMaps` drawing mapper. Changing recipe controls regenerates both previews with the same seed. Preview geometry is transient, cleared on rebuild/exit, and excluded from project history and exports. Preview mode is session UI state, not a recipe field. Pattern Brush and legacy accessory layout behavior stay unchanged.

Volume refinement: the starter uses a .95 depth/width ratio with a near-matching depth envelope, retaining at least 90% depth relative to width through the main body. Width, medium count/separation and disabled flyaways are unchanged. Only explicit starter loading picks up this revision; saved recipes and completed clumps keep their existing values.

Feature contract: accessory-only UI; recipe editor owns authored settings; preview defaults to Straight, explicit Ponytail load chooses Compare. Group/mirror/undo/project/export behavior for completed strokes remains the existing baked-clump behavior. Preview mode has no scene undo step, inheritance, mirroring or durable state. Acceptance: deterministic starter and independent curves/layers; straight/curved/compare rebuild and exit; draw/undo/reload a bundle using the same recipe. Tests cover pure paths and production rebuild with renderer/mapper doubles; user-led live review remains required for appearance, orbit, actual stroke geometry and persistence.

In Brushes → Accessory, enable **Procedural Bundle Recipe**. The straight preview uses the same template and `drawClumpStrandMaps` mapping as **Draw Bundle Recipe**. Main width, depth ratio and taper are independent of Draw Strand defaults. Medium locks and flyaways have separate counts, relative widths, root positions, lengths, surface following, tip separation and curl. The seed is stable; Reroll increments it. Changing one layer does not rerandomize the other.

Accessory points carry explicit arc-length parameters; they do not use the legacy full-length radial reconstruction. All strands follow the stroke's bend. Surface following controls taper-relative lateral placement, not independent bend following. This first version does not guarantee collision-free placement.

Save Recipe stores one current recipe in this browser, not a named preset library or preference backup. Reset changes the working recipe; Save makes it durable. A stroke captures a recipe copy at pointer-down. Completed strokes become ordinary editable clumps and use existing geometry, mirror, history, save/load and export paths. They are baked on creation; changing the builder does not regenerate existing clumps. No project schema change is introduced.
