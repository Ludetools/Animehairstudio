# Mesh chamfer bevel

The Meshes toolbar/radial Bevel settings box clips faces beside selected edges and replaces the crease with chamfer strips. One segment is flat; 2–12 segments follow a curved profile. Shared profile rails are welded and corner caps use local quad patches. The previous support-loop insertion and edge-flow smoothing are no longer the bevel implementation.

Contract: polygon meshes and base hair-shell meshes in edge mode; existing width .12 is a fraction of adjacent rail lengths, bounded .02–.45. Apply is one undo step; cancel/open is non-mutating. The existing mirror edge expansion and linked-mirror refresh are used. Existing project fields, presets and defaults remain unchanged. Polygon point attributes are interpolated from source weights and normals normalized; source face smoothing groups propagate, with a separate chamfer group. Selection clears after application because the original edge no longer exists.

Connected-edge pass: selected edges may share faces and vertices, form chains or closed loops, or meet at three-way corners. Face rails weld across unselected edges, edge strips meet at vertex patches, and local transition cuts pair odd-sided patches into quads. Unrelated disconnected components remain unchanged; there is no whole-mesh subdivision. Some adjacent faces may receive transition cuts to keep the quad-only editor contract. Source winding and output incidence are validated before commit. Unsupported/degenerate patches return no result before history or mesh mutation. Boundary/non-manifold edges are still rejected. Width remains relative rather than a world-distance offset. General collision/overlap clamping and full Maya/Blender feature parity are not implemented. Shared corners ease the rounding to avoid colliding profiles; the profile is not an exact circular fillet.

Interactive contract: the modeless settings box supports viewport left-drag width adjustment (Shift for precision), live width and segment controls, Apply/Enter and Cancel/Escape. Alt navigation remains available. Preview is a disposable neutral-blue mesh with topology lines; authored geometry and history remain untouched until Apply. Mode/tool changes and focus loss discard the preview. Width defaults to .12, segments to 1, both session-only controls; no new project, preset or group fields. Applied topology follows existing mesh save/load and mirror handling. Linked partner rendering is refreshed on commit, not in the temporary preview. Settings boxes for floating tools, extrusion, remesh, object transforms, reference images and bevel reserve space below the statistics box if their rectangles overlap; remaining height scrolls.

Segmented validation: module tests exercise 2/3/6/12 segments at .02/.2/.45 widths, outward nonzero triangles, welded incidence, Euler characteristic and source attribute weights. Isolated app checks cover six-segment chains, loops, three-way and all-edge selections, finite position/normal/UV buffers, OBJ quads, and one-step Undo/Redo. A real isolated mouse drag changes width without mutating source topology/history; Escape restores visibility and orbit controls. Apply/Cancel were exercised against production controllers with no page errors. General popup visual review across UI scales, full mirror previews, save/reload and downstream import were not exercised this pass.

Validation: cube edge removes the crease and reduces volume by the exact expected triangular-prism amount; every output edge has two oppositely directed face uses, all quads have nonzero area and outward winding. Tests cover chains, mirrored edge pairs, loops, three-way corners, all twelve cube edges, untouched disconnected geometry, open hinges and width extrema. In an isolated production app: single edge 6→10 faces, two-edge chain 6→10, three-way corner 6→14, loop 6→10, all edges 6→30. Position/normal/UV buffers are finite, OBJ face writer returns quads, each edit is one undo step, and Undo/Redo restores the expected face counts without page errors. Three-quarter normal-material/edge-overlay inspection confirms chamfer strips and joined corners on the all-edge cube. Native selection/dialog flow, linked mirror rendering, remaining camera angles and downstream OBJ import remain user-led. User scene not touched.
