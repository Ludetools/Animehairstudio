Anime Hair Studio Version 0.1.5 Patch Notes
August 12, 2026


NEW FEATURES

- Autosave and Crash Recovery
Anime Hair Studio can now keep a local recovery copy of your project while you work. Autosave runs after committed changes without interrupting active edits, and Preferences includes controls for enabling it and choosing how frequently it saves.

- Material Presets
You can now save a material as a reusable preset and apply it in other projects. Material presets retain the reusable appearance settings without carrying over project-specific material assignments.

- Base Color Gradients
Hair materials can now use an editable color gradient instead of a single base color. Gradient stops control how the color changes along the strand and are evaluated directly by the hair material for a responsive preview.

- Expanded Selection Sets
Selection Sets can now do more than recall a group of strands. Selected strands can be added to or removed from an existing set, and sets can hide, show, lock, unlock, or select all of their members from the outliner. The eye button beside a set controls the visibility of every strand in that set and shows a partial state when only some members are visible.

- Camera View Cube
A view cube is now available in the top-right corner of the viewport. Click Front, Back, Left, Right, Top, or Bottom to snap directly to that view. Top and Bottom use a stable camera orientation so normal orbiting still behaves correctly after leaving those views.

- Multi-Cam View
The experimental Multi-Cam option divides the viewport into four equal views. Each view has its own camera and can be activated by clicking inside it. Perspective remains freely orbitable, while cardinal views use orthographic projection with independent pan and zoom controls.

- Numeric Object Transforms
Object Edit Mode now includes a compact floating Transform panel. Translation, Rotation, and Scale can be entered directly, and each individual axis has its own reset button. Values update alongside viewport gizmo edits.

- Viewport Curve Controls for Move
Move tool settings can now expose Width, Depth, and Twist Curve controls directly on the strand. Width and Depth can switch between symmetrical and asymmetrical editing, and optional Width, Depth, or Uniform grab handles provide faster profile scaling in the viewport.

- Relax Position and Rotation Separately
The Relax tool now has independent Position and Rotation controls. Position follows the surrounding curve instead of simply flattening a point between its neighbours, while Rotation smooths the authored orientation and displays the normal direction in the viewport.

- Split Panel Tip Curvature
Split Panel strands now have a signed tip-curvature control for shaping curved fringes in either direction. Additional tip density can be added where the split needs more detail, and open split boundaries can be displayed as hard edges.

- Branch Surface Imprints
Attached branch strands can now project their profile intersection onto the parent strand as additional topology. The imprint remains part of the parent geometry when the branch is hidden, making it easier to inspect and develop connected branch shapes.


UI CHANGES

- Customizable Panel Styles
Preferences now offers three panel appearances: Default Panels, No Panels, and Glass Panels. No Panels extends the viewport behind the interface so controls appear to float over the scene. Glass Panels retains the panel structure while using the translucent glass treatment.

- Custom Glass Color
The Glass Panels color can be changed from Preferences or reset to the original dark color. The chosen color is shared by the side panels, workspace controls, top viewport controls, dropdowns, tabs, and other glass-styled interface elements while preserving their lighter and darker value differences.

- Responsive Viewport Header
The viewport header now uses compact square buttons aligned around the Workspace, Live Surface, and Layer controls. When horizontal space becomes limited, the buttons move to a second row while the main dropdown groups retain their spacing and avoid overlapping.

- Pie-Style Radial Menus
Radial actions are now arranged as clean pie-menu sectors with subtle dividers and a cyan hover gradient. Hovering over a submenu reveals its smaller actions in a nearby outer ring, while lower-priority commands remain in the list beneath the menu. Labels have also been shortened to keep actions readable at a glance.

- Cleaner Interface Interaction
Interface labels are no longer accidentally selectable during normal use, while text fields and Patch Notes remain selectable. No Panels mode also uses simplified scrollbars and transparent outliner region rows so the viewport remains visible behind the interface.


TWEAKS AND QUALITY OF LIFE

- Press Ctrl+H with strands selected to hide them. Press it with nothing selected to unhide all hidden strands.
- Rebuild Curve is available from the strand radial menu. It appears in the radial ring when space is available and in the action list when the ring is full.
- Ctrl+D and the other duplicate commands work with selected Guides and References in their respective workspaces.
- Strands can be dragged into another outliner region. Each moved strand is renamed for its new region and receives a unique number when needed.
- Isolated View and Live Surface changes are excluded from Undo history, keeping modeling history focused on project edits.
- Recognized viewport shortcuts work after using checkboxes, toggles, dropdowns, and sliders. Text and number fields retain normal text-editing behaviour.
- Hold S and drag to resize the Move or Smooth brush while keeping the cursor anchored at its starting position.
- Preserve Tips has an independent state for each applicable brush.
- Zipper controls share the curve control-point display size and respond to the Control Point Size preference.
- The UV checker remains responsive on larger hairstyles, and exported UVs use the expected orientation in applications such as Maya.
- Split Panel topology uses quads wherever the profile has enough width to retain distinct corners, with triangles limited to collapsed taper regions.
- Proportional Editing uses a lighter influence display that disappears immediately when the selection is cleared.
- Undo and Redo remain responsive when working with hairstyles containing many visible strands.
- Locked strands use a restrained grey treatment with a subtle translucent magenta wireframe.
- Viewport shadows update live as strands, guides, lighting, and the camera change.


BUG FIXES

- Linked mirrored strands correctly reverse asymmetric Width Curve profiles.
- Branch roots remain attached to their parent control points during object and hierarchical transforms.
- Attached branches retain their authored orientation when the parent is rotated through large angles.
- Open curve editor windows follow the active strand when the selection changes.
- Viewport Width, Depth, and Twist Curve controls stay attached to rebuilt strand geometry.
- Tool shortcuts remain available while editing viewport curve points and after interacting with compatible panel controls.
- Move Brush selection masking continues to update linked mirror instances.
- Undo preserves Move Brush curve and control-point overlays without revealing unrelated normal or zipper controls.
- Relax Rotation interpolates consistently across wrapped angles.
- Guide Capsule radius changes preserve the capsule's position.
- Standard object-mode marquee selection selects the strands inside the drag rectangle.
- Top and Bottom camera snaps preserve stable orbit behaviour when returning to a perspective view.
- Radial submenu labels, dividers, hover regions, bottom sectors, and action lists remain aligned and selectable.
- Panel content remains below its tabs, and responsive layouts behave consistently across Default, No Panels, and Glass Panels modes.
- Texture updates wait for valid image data, preventing the associated Three.js renderer warning.
- Open zipper boundaries receive their intended hard edges, while closed splits remain seamless.
